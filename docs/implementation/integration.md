# 整套系统装配、交接与验收

工程契约0.2.0；修订日期2026-10-23。业务基线v4.2，外部协议0.1.0。本文是待执行集成设计，非完成报告。[组件边界](boundaries.md) · [协作规范](../development/README.md)。

## 1. 集成输入

实现者使用同版本contracts/schema/architecture清单，不用大量适配代码掩盖字段或语义漂移。统一类型、runtime schema和共享fake由基座提供，不能各模块各复制一份。公共接口变更先集中处理，再让依赖任务跟进指定commit。


npm workspaces、@campussec包名、TypeScript strict与ES modules沿用工程约定；具体版本/驱动/SDK由可运行安装包小验证锁定。当前没有产品package/锁或共享testkit。

## 3. 无业务回调环的构造顺序

1. Clock/Id/Secret与S02存储/事件。
2. S04适配、S06证据、S09独立channels；它们不依赖应用协调者。
3. S08 HostAccess与Execution（只注入channels.bind），S10配置/报告，S11投递（只注入HostDeliveryPort）。
4. S07 RunBudget、InvestigationTools（含工具账本）、RequestService、RetentionService、ReviewPublicationPort；分别注入窄端口。
5. S05告警、S09 gateway（注入S07命令/工具与只读scope）、S03 Facade与S12。

构造不启动网络/监听/定时器，不使用顶层单例或未绑定代理绕过业务依赖。依赖不存在时明确构造错误；宿主能力不可用由已实现的UnavailableHostAccess报告。可以使用工厂，但不能返回静默成功占位。

恢复屏障：失效旧grant、核对主体、S07核实旧任务/hold、S11核实sending，再启动gateway、告警和tick。S03定时器防重入，完全退出不保证远端停止。实际组件依赖清单必须保持DAG。

## 4. 三条主要路径

| 路径 | 模块顺序与结果 |
|---|---|
| 告警/可选自动 | S04→S05入库/提醒→S06→S07请求/预算→S09通道→S10配置→S08执行→S09入口→S07工具→S04/S06→S10结果→S11 |
| 客户端主动 | S12→S03→S07，后续共用上行；无种子也可开始；人工核查/导出仍在客户端 |
| 对话委派 | S08可信来源→S09委派入口→S07→独立调查会话/取证→S10→S11→S08绑定原来源 |

初始投影先由S07协调S06准备，S10生成PreparedProfile，S08核实提交后由S07释放；工具发送后S09回调S07释放，prepared不得提前有效。结果与outbox同事务，投递重试不重跑模型。清理、人工修订发布也由S07用例协调同事务。

## 5. 并行批次与退出条件

| 批次 | 工作 | 退出条件 |
|---|---|---|
| A | S01/S02/S03基座、共享fake、检查；尽早列宿主M0计划 | 干净检出可安装/检查，最小真实写入重启回读，明确不可用能力 |
| B | S04/S06/S12起步2—3支线 | 固定commit、目录归属、共享接口及各自关键失败场景通过 |
| C | 逐步接S05/S10/S11及本地人工闭环 | 告警→证据→案件→核查→导出，真实模块替换fake |
| D | S07/S08/S09按组件协调；授权后核实M0 | 宿主认证、专用配置、可信通道、原来源回传逐项记录真实依据/缺口 |
| E | 受控模型调查、三入口及恢复 | 材料分支改变查询/停止，预算/取消/身份/投递竞态通过 |

任务实时状态在Issue，本表只定义阶段条件。宿主M0应尽早调查，未通过时离线模块继续，但完整P0保留未通过。任何基线降级需明确记录决定，不能以人工复制代替自动回传。

## 6. 跨模块验收矩阵

| 编号 | 场景 | 通过依据 |
|---|---|---|
| I01 | 重读同告警/重启 | 一个源身份，不重复通知/建案/派发 |
| I02 | 最后一页失败 | 已存页保留、边界不推进、partial |
| I03 | 零匹配/缺权 | 不同结果，缺权不排除风险 |
| I04 | 调查中改背景 | baseRevision冻结，旧结果不覆盖当前 |
| I05 | 抢最后工具/事件额度 | 预算与证据保存同事务，只一个成功 |
| I06 | 关闭自动或取消 | 先关工具，再abort；主动任务独立 |
| I07 | 204无匹配消息 | uncertain，不重提、不报成功 |
| I08 | 取消后响应晚到 | 不交付材料、不恢复旧grant |
| I09 | 保存结果/发送后崩溃 | 仅核实/恢复投递，不重跑模型 |
| I10 | 多订阅者取消 | 普通来源只退订，不取消原任务 |
| I11 | 主体/工作区变化 | 旧grant/缓存失效，不改投当前对话 |
| I12 | 无种子/缺范围 | 无种子可调查；缺范围不占模型名额 |
| I13 | 材料含命令/链接 | 不扩权、不执行、不自动外发 |
| I14 | 重复完成/修订 | 结果/投递唯一，CAS冲突和历史保留 |
| I15 | 到期/token未知 | 工具关闭，新启动按配置暂停 |
| I16 | 两证据分支 | 真实模型后续行为变化，非只比较文字 |
| I17 | 清理与缓存失效间失败 | 证据/缓存同回滚，不重放已清正文 |
| I18 | 发布修订排outbox失败 | 新结果版本与outbox同回滚，旧投递不变 |
| I19 | 完成与取消竞争 | S07唯一决定，S10不读私有请求状态另判 |
