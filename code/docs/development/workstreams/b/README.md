# B 线交接材料

本目录保存本线离线拆解、合成验收输入、接口需求和交接材料。实时状态只更新[对应任务](../../tasks/T003-b-local-domain.md)，不要在这里再维护进度表。

B0 材料入口：

- [实现拆解与依赖交接](b0-plan.md)：S02/S05/S06/S10 的可复用部分、后续工作单元及跨线请求。
- [表、端口和事务映射](b0-boundaries.md)：写所有权、同步事务、外部 I/O 和失败边界。
- [机器可核对的映射](b0-mapping.json)：覆盖 B 线全部业务表及服务方法，不是新产品契约。
- [合成输入](b0-fixtures.json)与[验收场景及预期](b0-scenarios.json)：供 B1—B4 实现测试使用；场景预期尚未由产品实现执行。
- [验收材料说明](b0-acceptance.md)与[离线核验脚本](verify_b0.py)：只检查材料、规范和原生 DDL，不调用模型、平台或产品服务。

从仓库根运行 `python -B code/docs/development/workstreams/b/verify_b0.py`。脚本按自身位置寻找仓库，也可从其他目录运行；仅使用 Python 标准库和临时 SQLite，不安装产品依赖。

共享配置/锁/契约/fake 需求说明具体调用场景与消费者，交 A 串行处理；迁移需求交 B。真实环境证据注明授权、执行者、日期、版本和样本，不把原件或凭据放入本目录。
