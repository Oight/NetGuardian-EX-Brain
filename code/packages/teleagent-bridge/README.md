# S08 · 宿主与执行

2026-10-24 新增[固定版本独占后端适配](execution/teleagent/index.ts)，已接生产 compose；本机实际版本为 2.7.0。真实后端合成工具链与两次真实桌面模型任务分别通过，完整 M0 仍有可信委派/外部投递缺口。接入方式、证据和限制见[本轮验证](../../docs/verification/teleagent-m0-2026-10-24.md)。默认不读取桌面凭据或自动启用宿主。

execution 实现持久提交/观测/中止意图、冻结输入校验、响应关联、超时未知与禁止重复提交；host-access 实现可信来源存储、不可重定向的绑定与原会话投递窄端口。ExecutionWire/HostWire 是版本接口适配依赖，默认缺失时明确不可用，不生成成功响应。

此前另一设备静态核对对象为 TeleAgent Windows 2.7.1，安装包中存在会话/消息/中止 SDK 路由；该记录不是本机 2.7.0 的兼容性成绩。可信来源会话证明和外部消息回传仍有缺口。默认生产入口不读取个人会话、进程参数或凭据来猜测接入。

离线组合测试不等于真实 Windows 宿主验收；当前边界见[全项目核验](../../docs/verification/project-audit-2026-10-24.md)。
